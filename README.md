# ClinicoPathShiny

R Shiny drafts for clinicopathological research. The existing application is a
prototype; the new delivery architecture and Python companion are planned.

Start with the [joint development plan](docs/shiny-development-plan.md), prepared
2026-11-07. Implementation backlogs:

- [R Shiny modernization](docs/r-shiny-roadmap.md)
- [ClinicoPathShinyPython](docs/python-shiny-roadmap.md)
- [Reuse assessment of eleven earlier projects](docs/prior-shiny-projects.md)

The plan proposes browser access, institution-hosted deployment, and later
double-click local launchers. It does not establish that the existing application
is ready for public hosting or that either version has feature parity with jamovi.

No application code was changed during preparation of these plans.
